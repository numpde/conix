Conix Make operator interface — 10 November 2026
=================================================

Public targets use <resource>[/<role-or-subject>]/<action>, with exact operator
inputs, no Make-expression interpolation, no implicit image/wheel acquisition,
and one explicitly chosen local Docker Engine per command.

Current T0-4 state: the indexer-labelled runtime image installs the generic
ABI codec, catalog, PostgreSQL journal, blockHash scanner and checkpoint reader.
Owner-only schema initialization exists as an explicit Python API. A production
worker deployment/apply command is not yet available. The old PayToPlay-specific
scanner and test targets remain retired; a contained image smoke test does not
prove that a production worker has been deployed.

T0-5 real-contract acceptance is an opt-in owned dapp32 campaign outside
ordinary CI. Note 004, section 8.8, records its qualification evidence.

Available operations
--------------------
test/repository/run                Offline host tests, no Docker or secrets.
repository/inputs/check            Offline lock and build-context admission.
image/{python-base,postgres,dockerfile-frontend,foundry}/acquire
                                   Explicitly pull reviewed pinned images.
wheelhouse/{check,acquire}         Existing shared pool inspection or
                                   explicitly authorized missing acquisition.
image/{indexer,test-runner,evm-test-runner}/build
                                   Build offline from exact streamed inputs
                                   and locked wheels; return immutable image ID.
image/{indexer,evm-test-runner}/check
                                   Confined networkless installed-code smoke;
                                   NOT a running indexer qualification.
test/postgres/run                  Disposable PostgreSQL plus isolated
                                   Anvil: two owner-initialized sources,
                                   real raw-log scanner/journal tests and
                                   restricted runtime/reader privileges.
test/input-staging/run             Private TOML/ABI/DSN envelope staging,
                                   installed catalog admission under the
                                   runtime UID and owned cleanup.
deployment/inputs/create           Retain one ownership-labelled private
                                   input volume after catalog admission.
deployment/inputs/remove           Remove only an explicitly selected
                                   ownership-verified private input volume.
deployment/config/check            Read-only inspection of a constrained
                                   *prospective* Compose graph; no worker.
deployment/status                  Inspect a previously owned Conix project.
deployment/remove                  Retire selected labelled Conix indexer
                                   containers, retaining external DB, networks
                                   and private input volumes.
test/indexer/acceptance/run        Borrow an externally prepared dapp32
                                   PayToPlay fixture under strict source and
                                   network verification; own only Conix SQL.
campaign/indexer/acceptance/run    Own a freshly created dapp32 producer,
                                   run full generic acceptance including
                                   restart and reorganization repair, and
                                   retire consumer before producer.

Selectors
---------
DOCKER_CONTEXT             Explicit local Docker context (no ambient fallback).
WHEELHOUSE                 Explicit existing host-local pinned wheel pool.
IMAGE                      Exact immutable image ID for one-image check.
RUNNER_IMAGE               Exact immutable test-runner image ID.
INDEXER_IMAGE              Exact immutable installed core library image ID.
FIXTURE_DESCRIPTOR          Existing private owner-owned mode-0600 descriptor.
DAPP32_DIR                  Explicit absolute dapp32 checkout (owned campaign).
CONFIG_FILE, DSN_FILE       Absolute paths to operator-owned staged inputs.
                           Each staged abi_file is abi/<name>.json beside
                           CONFIG_FILE. Keep the DSN source mode 0600. A
                           final LF or CRLF terminates the credential line.
INPUT_VOLUME               Exact ownership-labelled staged resource ID.
DEPLOYMENT                  Exact selected Conix deployment name.
DATABASE_NETWORK, RPC_NETWORK  Explicit separate pre-existing networks.

The dapp32 descriptor establishes test deployment facts, not cleanup rights.
Only the producer's verified up/info/down contract grants owned-fixture cleanup.
The host admits the private producer descriptor; test consumers receive only
the public PayToPlay ABI and role addresses, while the owner receives a
narrower source record. No child receives producer wallet keys. The test-only
Foundry Cast binary stays in the EVM runner image, not the product wheel.

The host copies the exact declared ABI files alongside the configuration
and DSN into one private volume. The installed catalog validates the staged
inputs offline with the volume mounted read-only as UID/GID 65532. This
prepares the inputs for operator use. The owner-only initializer exists as
a Python API and has no Make action yet.
